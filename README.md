# 福彩3D模拟分析工作台

这是一个基于 Python 和 Streamlit 的 福彩3D 历史数据模拟分析系统。项目用于导入近5年历史开奖数据，完成数据校验、模型训练、时间顺序回测、候选号码排序、胆码/七码/直选Top20 等模拟分析展示。

本工具仅用于学习和模拟研究，不代表真实预测，不建议用于投注。模型相对分数不是中奖概率，只用于排序。

## 主要功能

- 近5年历史数据加载、上传、校验和清洗
- 通过在线接口获取最新数据，并补全本地 CSV 数据仓库
- 统计模型和机器学习模型训练
- 严格时间顺序回测，避免使用未来数据
- 候选号码 TopK 排序展示
- 下一期3个胆码模拟排序
- 不定位7码模拟筛选
- 定位7码模拟筛选
- 直选Top10 / Top20 / Top50 回测统计
- 直选20注全覆盖快捷方案
- 回测统计审计、随机基线对比和显著性提示
- 亮色 / 暗色高对比主题切换
- Markdown 报告导出
- 全部343组合导出

## 环境要求

建议使用 Python 3.10 或更高版本。

核心依赖：

```bash
pip install streamlit pandas numpy plotly scikit-learn pytest
```

可选依赖：

```bash
pip install torch xgboost lightgbm catboost
```

说明：

- `torch` 用于可选的 TabResNet 模型。
- `xgboost`、`lightgbm`、`catboost` 如果未安装，页面会自动跳过对应模型。
- 系统可以只使用统计模型和 scikit-learn 模型运行。

## 快速启动

在项目根目录运行：

```bash
streamlit run fc3d_workbench.py --server.port 8501
```

启动后打开：

```text
http://127.0.0.1:8501
```

如果 8501 端口已经被占用，可以换一个端口：

```bash
streamlit run fc3d_workbench.py --server.port 8502
```

## 数据格式

CSV 文件必须包含以下字段：

```csv
issue,date,number
2026142,2026-06-01,894
2026143,2026-06-02,376
2026144,2026-06-03,726
```

字段说明：

| 字段 | 含义 | 示例 |
|---|---|---|
| `issue` | 开奖期号 | `2026144` |
| `date` | 开奖日期 | `2026-06-03` |
| `number` | 三位开奖号码 | `726` |

注意：

- `number` 必须是 3 位数字。
- 如果号码包含前导 0，例如 `018`，CSV 中必须保留为文本或补齐为 3 位。
- 数据必须按真实开奖时间校验，系统会在清洗时排序和检查。

## 使用流程

1. 打开页面后，在侧边栏选择亮色或暗色主题。
2. 上传 CSV，或点击“加载近5年开奖记录”。
3. 如需补齐本地缓存缺失的新期开奖，点击侧边栏“获取最新数据”。
4. 点击“校验数据”。
5. 点击“训练模型”。
6. 点击“开始回测”。
7. 查看回测结果、随机基线、统计审计。
8. 点击“生成候选”。
9. 查看候选号码、胆码、不定位7码、定位7码和直选组合结果。
10. 到“导出”页下载 Markdown 报告或 CSV。

## 当前快捷方案

页面“快捷方案”区域提供以下一键配置。

| 快捷按钮 | 用途 | 配置 | 历史回测记录 |
|---|---|---|---|
| 一键配置7码覆盖优先 | 不定位7码 | `c=0.1,o=0.2,s=0.4,h=0.3`，`top_sum >= 4.000389` | 7码=23：`270/329 = 82.07%` |
| 一键配置定位7码 | 百十个位各7码 | `history_frequency`，`min_top7_share <= 0.716771789` | 三位全中：`23/57 = 40.35%`；至少2位：`51/57 = 89.47%` |
| 一键配置胆码最优 | 3个胆码 | `c=0.3429,o=0.1322,s=0.288,h=0.237`，全量输出 | 至少命中1个：`239/351 = 68.09%` |
| 一键配置直选20 | 直选Top20组合排序 | `h=0,b=0.3,o=0.2,s=0.5,p=0`，全量输出 | 近半年Top20：`8/173 = 4.62%` |

权重缩写：

| 缩写 | 含义 |
|---|---|
| `c` | 组合边际分数 |
| `o` | 遗漏值回补 |
| `s` | 和值分布支持 |
| `h` | 冷热稳定性或历史频率，具体以对应模块说明为准 |
| `b` | 贝叶斯平滑频率 |
| `p` | 位置频率 |

这些快捷方案来自历史回测搜索，只能说明历史样本中的模拟表现，不能说明未来开奖结果。

## 回测口径

系统强调时间顺序：

- 每一期回测只使用当前期之前的数据。
- 回测结果会和理论随机基线对比。
- 页面会显示命中率、命中次数、理论期望、差值、置信区间、近似 p 值和显著性判断。
- 如果模型没有显著超过随机基线，应按模拟排序参考理解。

常用随机基线：

| 指标 | 理论基线 |
|---|---:|
| 直选Top10 | 约 1.00% |
| 直选Top20 | 约 2.00% |
| 直选Top50 | 约 5.00% |
| 单个位 Top7 | 约 70.00% |
| 三位同时落入定位7码集合 | 约 34.30% |
| 3胆码至少命中1个位置 | 约 65.70% |
| 3胆码至少命中2个位置 | 约 21.60% |
| 三个开奖号位置都落入胆码集合 | 约 2.70% |
| 三个胆码全部出现在开奖号码去重集合 | 约 0.60% |

## 常见问题

### 1. 页面打开后文字看不清怎么办？

在侧边栏顶部切换“亮色 / 暗色”主题。如果侧边栏收起，点击左上角菜单按钮展开。

### 2. 为什么有些按钮是灰色的？

系统按流程启用按钮。例如没有校验数据前，训练、回测、生成候选会暂时禁用。禁用按钮仍然会保留可读文字。

### 3. 为什么模型结果和随机基线接近？

福彩3D 是随机性很强的数字序列。历史数据未必存在稳定可学习规律，所以必须看长期回测、随机基线和显著性，而不是只看某一次结果。

### 4. 可以每期都使用快捷方案吗？

技术上可以一键配置并生成候选，但快捷方案只是历史样本中的模拟参数。实际使用时仍应把它理解为排序参考。
